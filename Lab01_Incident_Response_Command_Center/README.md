# Lab 01 — Multi-Agent Incident Response Command Center

Standalone Claude Code subagents lab for VS Code + Ubuntu. No database, Tavily, MCP, or additional Python packages. All evidence is synthetic.

## Start
1. Open **this folder** in VS Code, and open an Ubuntu terminal here.
2. Run `python3 -m unittest discover -s tests -v` to validate fixture integrity.
3. Run `claude` from this directory. If it was already running elsewhere, restart it here.
4. Follow `LAB01_STUDENT.md`.

**Note:** In current Claude Code versions, the `/agents` interactive wizard may be removed; these `.claude/agents/*.md` definitions are the source of truth. Verify actual named delegations in the execution view; a written claim is insufficient.
